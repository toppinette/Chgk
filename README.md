# chgk-copilot-bot

Telegram-бот для `rating.chgk.info`.

Что уже реализовано:
- авторизация пользователя rating через Telegram (`POST /authentication_token`);
- выбор роли: игрок, капитан, представитель, организатор, редактор, тестер;
- сценарий для роли `организатор`:
  - выбор даты кнопками в inline-календаре (следующие 3 недели) или ручной ввод;
  - получение всех турниров типа `С` (синхрон) на выбранную дату;
  - вывод каждого турнира отдельным сообщением: название, редакторы, заявленная сложность;
  - выбор турниров для голосования;
  - создание Telegram-опроса по выбранным турнирам.

## Команды
- `/start` - старт и меню
- `/login` - авторизация в rating
- `/logout` - выход (очистка rating-токена)
- `/role` - выбор роли
- `/date` - выбрать дату для списка синхронов (только для организатора)
- `/poll` - создать опрос из выбранных турниров
- `/cancel` - отменить текущее действие

## Локальный запуск
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните TELEGRAM_BOT_TOKEN
export $(grep -v '^#' .env | xargs)
python -m bot.main
```

## Деплой на Render
В репозитории уже есть `render.yaml` с worker-сервисом.
Для сохранения ролей и токенов между деплоями используется persistent disk (`/var/data/bot.db`).

1. Запушить проект в GitHub/GitLab/Bitbucket.
2. В Render выбрать **New +** -> **Blueprint** и подключить репозиторий.
3. В переменных окружения задать `TELEGRAM_BOT_TOKEN`.
4. Запустить деплой.

## Важное по безопасности
- Не храните `TELEGRAM_BOT_TOKEN` в коде.
- Бот хранит только JWT-токен rating (не пароль) в SQLite.
- Если токен Telegram уже был публично показан, лучше сразу перевыпустить его через `@BotFather`.
